# 三国弈

保留中国象棋棋子、16 枚开局阵型与基本走法的网页游戏。支持魏、蜀、吴三人同屏轮流对弈，以及原版 9 路 10 行双人经典模式。

## 运行

需要 Node.js 20.19+ 或 22.12+。

Windows 下双击项目根目录的 `启动三国象棋.cmd`，启动器会检查依赖、重新构建并打开 `http://127.0.0.1:5188/`。游玩时保持启动窗口打开，按 `Ctrl+C` 关闭服务。

也提供离线文件 `三国弈.html`，直接双击即可对弈，无需运行服务。每次 `npm run build` 会重新生成这个文件。离线文件与本地网址分别保存各自的棋局。

也可以在终端运行：

```powershell
npm install
npm start
```

`npm start` 使用同一固定地址，不会因端口占用悄悄改到另一个网址。页面需要服务运行；仅打开源代码目录里的 `index.html` 不能启动游戏。

开发时可以使用：

```powershell
npm install
npm run dev
```

打开终端显示的本地网址，默认 http://127.0.0.1:5173/ 。

```powershell
npm test
npm run build
npm run preview
```

生产文件位于 `dist/`，可由普通静态网站服务器托管，无需后端。恢复后的象棋页面位于 `src/chess.ts` 和 `src/chess.css`，入口 `src/main.ts` 仅加载象棋。原先射击游戏源码保留在 `src/fps.ts`，旧入口与构建备份在 `artifacts/before-chess-restore/`。

## 玩法

- 默认魏国先行，依次魏 → 蜀 → 吴。本作是同屏棋盘，三位玩家共用设备。
- 每国开局 16 枚棋子：一将、两士、两象、两马、两车、两炮、五兵卒。
- 车直走、马走日并检查马腿、炮隔一子吃子、相走田并检查象眼且不过河、士将限本国九宫。
- 兵卒未过河只能前进，过河可以前进或横走，始终不能后退。
- 不能自陷将军，不允许将帅照面。将死或困毙在该国轮到落子时判负。
- 点击本国棋子后点击合法位置完成走子。支持键盘 Tab 选择棋子、Enter/空格操作，Esc 取消选择。
- 支持可走位置提示、上一着悔棋、旋转视角、专注模式、落子音效与文字棋谱导出。
- 点击棋盘下方「棋子配色」或棋盘顶部调色图标，可分别选择魏、蜀、吴的颜色。支持色块选择和六位十六进制色值输入，实时更新棋面与阵营标记；文字会自动适配黑白对比。提供鲜明配色、原有配色与恢复默认，配色自动保存，悔棋、重新开局或切换模式时保留。
- 当前棋局和最多 100 步悔棋快照自动存入当前浏览器的 localStorage。刷新可以续局，存档损坏时恢复新局。浏览器存储不可用时仍可以游玩。

## 三国扩展规则

三人象棋没有与两人原版完全相同的棋盘。本作将三个完整的九路五行半场对称排布，以河界线路互通；各国本阵保留原版。

每国河岸上的 1–4 路通向顺序中的下一国、6–9 路通向上一国，过河后的路数镜像对应（1 对 9、2 对 8 等）。中间第 5 路可选择另外任一国。车炮跨河后继续沿对岸纵线走，马在跨河时仍检查马腿。

兵卒过河后锁定进入的敌国，朝该国底线前进，可横走，不能退回河界或改变进军目标。相、士、将始终留在本国半场/九宫。

出局方的棋子全部移出棋盘，其阵地仍可通行。出局方之后不再参与轮转；最后一国获胜。可在页面「棋规」中查看规则。

经典模式使用原版两人棋盘、阵型、走子与将军规则。当前没有联网房间、AI 对手、赛事计时或长将/长捉裁决。

## 技术

TypeScript + Vite，使用 SVG 绘制可交互棋盘，无框架与图片素材依赖。规则引擎、存档校验与颜色处理有 Node 内置测试覆盖。
